# Bangladesh delivery coverage
The Flyway migration contains 8 divisions and 64 district records. The customer UI does not ship a static district list: it reads `GET /api/coverage/districts`, which returns only districts where both the district and at least one delivery-coverage row are enabled in PostgreSQL. Initially this is Dhaka district/city only. Enabling a district is not sufficient to establish neighborhood-level serviceability; add reviewed city/area coverage, service hours, fees, and operational capacity before launch. GPS coordinates are not sent or reverse geocoded. Order creation remains disabled until the backend can validate current menu prices and enabled delivery coverage. No fabricated restaurant listings are seeded.

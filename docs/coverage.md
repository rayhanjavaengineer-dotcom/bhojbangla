# Bangladesh delivery coverage
The Flyway migration seeds all 8 divisions and 64 districts. The customer UI uses the same district metadata for selection; the public `GET /api/coverage/districts` endpoint reads the complete list from PostgreSQL and exposes the enabled flag. Only Dhaka district/city is initially enabled. Enabling a district is not sufficient to establish neighborhood-level serviceability; add reviewed city/area coverage, service hours, fees, and operational capacity before launch. Order creation remains disabled until the backend can validate a current menu price and an enabled delivery coverage record. No fabricated restaurant listings are seeded.
